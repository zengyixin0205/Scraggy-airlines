## Scraggy image

The site looks for `assets/scraggy.png`. If that file is missing it shows `assets/scraggy-placeholder.svg`, a generic original placeholder mascot made for this project.

To use a Scraggy image you found online:

1. **Download** the image and save it as `assets/scraggy.png` (do not link to it on the other website: hotlinked images break and use the other site's bandwidth). A transparent background works best.
2. Prefer fan art or a sprite whose licence allows reuse.
3. Record it below.
